## Key Design Decisions

### Why AsyncOpenAI?
FastAPI is async-first. Using AsyncOpenAI prevents blocking the event loop.

### Why Separate dedup + classifier?
Single Responsibility Principle. Each service has one job, making code testable.

### Why lead_tags table?
Allows tags to be managed separately from leads. Supports many-to-many relationships.

### Why singleton database client?
Connection pooling efficiency. One Supabase client per app, not per request.

### Why temperature=0.3?
Deterministic classifications. Same lead gets same score every time.
